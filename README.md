
# Smart Route Optimizer Using Dijkstra's Algorithm

A Python project that finds optimized routes between locations using Dijkstra's shortest-path algorithm.

## Features

- Shortest-path calculation using Dijkstra's algorithm
- Weighted road network with traffic penalties
- Alternative route comparison
- Estimated travel time and fuel cost
- Graph visualization with the selected route highlighted

## Technologies Used

- Python
- NetworkX
- Matplotlib
- heapq

## Installation

Install Python, then install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python main.py
```

Enter a source and destination from the locations displayed by the program.

## Algorithm

Dijkstra's algorithm uses a priority queue to find a minimum-cost path through a graph with non-negative edge weights. This project combines road distance with a traffic penalty to calculate route cost.

## Notes

The included road network and traffic values are demonstration data. Travel-time and fuel-cost values are estimates, not live traffic or GPS information.
